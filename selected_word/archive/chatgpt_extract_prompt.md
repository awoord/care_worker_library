# ChatGPT 用：単語抽出プロンプト

## 事前フィルタ（推奨）

ChatGPT に渡す前に、ルールベースでノイズ候補を除外する:

```bash
cd selected_word
python3 extract_noise_candidates.py
```

- 入力: `extracted.csv`
- 出力: `noise_candidates.csv`（除外候補・理由付き）, `extracted_for_chatgpt.csv`（ChatGPT用）
- 手動追加: `noise_blocklist.txt`（1行1語）
- 厳しめ: `python3 extract_noise_candidates.py --mode strict`

**ChatGPT には `extracted_for_chatgpt.csv` を渡す**（`extracted.csv` 全文より精度が上がりやすい）。

---

## 推奨バッチサイズ

| 項目 | 推奨 |
|---|---|
| **入力** | `extracted.csv` **全文（約4,270語）を1回で渡す** |
| **出力** | **120〜150語**（最終チェックしやすい上限） |
| **1回の上限** | 出力200語まで（それ以上は漏れチェックが難しい） |

入力を分割すると「全体の中での重要度」がブレるため、**4269語は1プロンプトで渡す**のが最適です。  
すでに db 登録済みの語リスト（`db_words.csv`）も同時に渡してください。

---

## プロンプト（コピペ用）

```
あなたは、日本語を母語としない介護福祉士受験生向けの語彙選定の専門家です。

【目的】
国家試験の「合格」ではなく、次の文章が読めるようになることです。
- 国試問題文の日本語
- 過去問解説テキストの日本語
- 専門用語の解説文（その解説を読むための「一般語彙」を補う）

生徒は専門用語自体より、解説文を構成する一般語彙（動詞・形容詞・抽象名詞・接続表現）が不足しています。

【入力】
1. extracted.csv … 国試10年分の頻出語（単語,出現回数）。db未登録のみ。
2. db_words.csv … すでに学習アプリに登録済みの単語（dbシート行順・これらは選ばない）
3. （任意）requested.csv … 生徒からの追加希望語（あれば必ず含める）

【選定基準 — 優先して選ぶ】
- 解説文の骨格になる語（例：含む、区分、過程、総合、事例、対策、程度、割合、効果、影響、維持、改善、評価、確認、説明、適切、関連、背景、前提、一般、通常、増加、分類、感情、状態、対応）
- 国試文・解説文で繰り返し出るが、JLPT N4以下の初級語ではない語
- 専門用語の説明文を読むときに「つまずきやすい」中級の一般語
- 出現回数が低くても、読解上重要な一般語（例：放置、豊富、貢献、活発）は積極採用

【選定基準 — 選ばない】
- db_words.csv に既にある語
- 制度名・法令名・試験名（例：厚生労働省、法定雇用率、国家試験）
- 施設種別の固有名詞（例：介護老人保健施設、デイサービス）
- 疾患名・解剖部位の専門語（例：脳梗塞、咽頭、頸髄、下垂体）※解説文の一般語が目的のため
- 医療機器・略語（例：ADL、ICF、ALS、カニューレ、カテーテル）
- 日常会話の初級語のみで構成される語（例：コーヒー、スーパー、財布）
- カタカナ外来語で、一般読解に必須でない語

【出力形式】
CSVのみ。ヘッダー付き。説明文は不要。

【注意】
- 英語・ルビ・意味・例文は書かない（別工程でGeminiが生成）
- 同義語の重複を避ける
- 判断が分かれる語は「要確認」と理由に付記

## 2段階にする場合（精度優先）

1回で150語が不安なとき：

1. **第1段階**：上記プロンプトで **300語** を「候補」として抽出
2. **第2段階**：300語だけを渡し、「同じ目的で最重要150語に絞れ」と依頼

## Gemini への引き継ぎ

ChatGPT の出力 CSV（単語,出現回数,選定理由）を人間が確認・修正したあと、  
Gemini には `done_explanation.csv` の形式例を渡して意味・例文を生成させます。
