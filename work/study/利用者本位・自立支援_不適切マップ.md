# 国試で✕になる選択肢（ソース）

`bad.txt` の不適切な選択肢を、適切マップと対照のカテゴリで並べた一覧。
選択肢の文言は要約せず原文のまま。断片で意味が通らないものだけ（　）で主語補足。カテゴリ名と要約だけ要約。

- 公開: `/kaigo/kakomon/themes/hikaku-jiritsu-ng.html`
- 再生成: `python3 work/study/build_jiritsu_ng_hikaku.py`
- 出典: `bad.txt`（現行＋過去10年追加）
- ページ: ✕=`hikaku-jiritsu-ng.html`／◯=`hikaku-jiritsu.html`
- 番号・【】は `var(--muted)`。【】クリックで過去問表示
- 対になる適切マップ: `利用者本位・自立支援_適切マップ.md`
- 並び: 6カテゴリ（文言内容で振り分け・適切マップと対。身体優先は✕単独）
