# 国試で◯になる選択肢（ソース）

原則リストの適切な選択肢と、`proper.txt`／`kaigo_katei.txt` を合わせた一覧。  
選択肢の文言は要約せず原文のまま。文脈補足の（　）は、外しても意味が通るものは外す。カテゴリ名と要約だけ要約。

- 公開: `/kaigo/kakomon/themes/hikaku-jiritsu.html`
- 再生成: `python3 work/study/build_jiritsu_hikaku.py`
- 出典: `利用者本位・自立支援（原則）.txt`（青）／`proper.txt`・介護過程拡張（赤）
- ページ: ◯=`hikaku-jiritsu.html`／✕=`hikaku-jiritsu-ng.html`
- 対になる不適切: `利用者本位・自立支援_不適切マップ.md`
- 番号・【】は `var(--muted)`。過去問はクリックで従来どおり表示
- 並び: 5カテゴリ（文言内容で振り分け）
- 誤答は扱わない（既存の正解文言は変更しない）
