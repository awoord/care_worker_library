## 1　理念

### 覚えること

- 介護保険法は、**国民の共同連帯**の理念に基づいて制度を設けている。
- 介護保険法第1条の趣旨は、介護が必要になった者が**尊厳を保持**し、その有する能力に応じ**自立した日常生活**を営めるよう、**保険給付**を行うこと。

### ×になりやすい点

| ×の主張 | 正しい側（国試で問われた区別） |
|----------|--------------------------------|
| 高齢社会対策の基本理念を定める | → **高齢社会対策基本法** |
| 福祉サービス利用者の利益保護・地域福祉の推進 | → **社会福祉法** |
| 疾病・出産などの保険給付 | → **健康保険法**など |
| 老人の福祉の原理・措置 | → **老人福祉法** |
| 高齢者虐待防止法は福祉六法の一つ | → 福祉六法には**含まれない** |
| 障害者総合支援法が障害者基本計画の策定を義務づけ | → 定めるのは**障害者基本法** |
| 社会福祉法が社会福祉士の定義を規定 | → **社会福祉士及び介護福祉士法** |
| 医師法が介護福祉の業務として医行為を認める | → 医師法は医行為を**医師の業務**として定める |

## 2　保険者・被保険者

### 覚えること

- **保険者**は、**市町村及び特別区**。
- **第1号被保険者**は **65歳以上**。
- **第2号被保険者**は **40歳以上65歳未満**の**医療保険加入者**（20歳からではない）。
- 加入は任意ではなく**強制加入**。
- 第1号の保険料の徴収は**市町村**（都道府県ではない）。
- 第2号の保険料の徴収は**医療保険者**（国ではない）。
- 保険者の事務の例として、**保険給付に関する事務**がある。

### ×になりやすい点

| ×の主張 | 正しい側 |
|----------|----------|
| 保険者＝厚労省・国保連・年金機構・支払基金 | → 保険者は**市町村・特別区**。他は別役割（審査支払・所管・年金など） |
| 第2号は20歳以上65歳未満 | → **40歳以上**65歳未満 |
| 第1号保険料を都道府県が徴収 | → **市町村** |
| 第2号保険料を国が徴収 | → **医療保険者** |
| 居宅サービス事業者の指定／認定基準の設定／審査会の設置／ケアマネ登録が保険者の役割 | → 多くは国・都道府県側。保険者の中核は**給付事務**など |

※事業者指定は制度改正で市町村指定が増えているが、出題当時の「保険者の役割」としては給付事務が正解側。

## 3　財源・負担

### 覚えること

- 財源は **公費 ＋ 第1号保険料 ＋ 第2号保険料**。
- 第1号保険料は**市町村ごと**（全国一律ではない）。徴収は市町村。
- 第2号保険料は**医療保険の保険料と合わせて**医療保険者が徴収（年金の特別徴収ではない）。
- 利用者負担は所得等に応じ**1〜3割**（一律1割ではない）。一定以上の所得で**3割**が導入された。
- **保険給付には支給限度額がある**。
- 40歳以上65歳未満でも**特定疾病**があれば給付対象（65歳未満＝対象外ではない）。
- **居宅介護住宅改修費**の支給限度基準額は**20万円**。
- 要介護度が変わっても、**保険料・利用者負担割合・食費・居住費**は変わらない（変わるのはサービス費など）。例: 認知症対応型共同生活介護費。
- **居宅介護サービス計画費（ケアプラン）に自己負担はない**。
- 施設の食費・居住費は原則自己負担（補足給付あり）。補足給付では**資産も勘案**する。

### ×になりやすい点

| ×の主張 | 正しい側 |
|----------|----------|
| 財源＝保険料だけ／公費だけ／第2号なし／「支援金」 | → **公費＋1号＋2号** |
| 第2号を年金保険料と合わせて徴収 | → **医療保険**と合わせて徴収 |
| 負担一律1割 | → **1〜3割** |
| 認定有効期間は原則3か月 | → 新規原則**6か月**、更新**12か月**など |
| 福祉用具貸与は要介護3以上のみ | → 要介護度に応じて対象（3以上限定ではない） |
| 地域包括への相談前に認定必須 | → **認定前でも相談可** |
| 認定前はサービス利用不可 | → **暫定利用可** |
| 認定に利用者負担2割 | → 認定そのものに負担割合はない |

## 4　認定・利用

### 覚えること

- 要介護認定の申請・処分は**介護保険の保険者（市町村等）**。
- 認定には**主治医意見書**が必要。審査判定は**介護認定審査会**（医療機関への委託ではない）。
- 認定は**被保険者証交付の後**に申請・認定する流れ（交付前に認定、ではない）。
- **居宅サービス計画の作成は、原則として要介護認定の後**。
- 施設サービス計画は**施設の介護支援専門員**が作成（地域包括ではない）。
- 認定結果は通常**1か月程度**かかる。申請から2週間なら「もう少し待つ」が妥当。
- **介護予防サービス・支援計画書**は、地域包括の**主任介護支援専門員**などが作成。
- 障害福祉サービス利用者でも、65歳以降は介護保険が優先される場合がある。**共生型**なら通所介護など継続利用できる旨を伝えられる。
- 共生型サービスの例として問われたもの: **通所介護（デイサービス）**（訪問看護・同行援護・通所リハ・障害GHは対象外として×）。

### ×になりやすい点

| ×の主張 | 正しい側 |
|----------|----------|
| 認定の問い合わせ先＝主治医・調査員・再申請 | → 通常期間内なら**待つ** |
| 審査判定＝医療機関が行う | → **介護認定審査会** |
| 障害者は75歳で介護保険へ | → 第1号は原則**65歳** |
| 予防計画書＝訪問介護員・サ責・生コ・サビ管が作成 | → **地域包括の主任ケアマネ**等 |

## 5　地域包括

### 覚えること

- **地域包括支援センター**は、総合相談・権利擁護・包括的・継続的ケアマネジメント支援などの拠点。認知症が疑われる一人暮らし高齢者の**最初の地域相談先**としても適切。
- **地域ケア会議**の開催は地域包括の業務。個別ケースの課題分析から**地域課題の把握**につなげる。
- **フォーマルサービス**の例: 地域包括支援センターへの相談。見守り住民・家族の手伝い・ボランティア・友人の相互扶助はフォーマルではない。
- 民生委員からの地域課題の相談は受けとめ、**関係者と地域ケア会議で話し合う**。

### ×になりやすい点

| ×の主張 | 正しい側 |
|----------|----------|
| 本人来所が原則で門前払い | → 民生委員等の相談も受けとめる |
| すぐ個人のケアプラン作成 | → 地域課題には**地域ケア会議** |
| 民生委員のかかわりを制限 | → 見守り強化に逆行 |
| 実態把握のため審査会を設置 | → 審査会は**不服申立て**の機関 |
| 施設ケアプラン作成・成年後見申立・認定審査会設置・地域密着の指導監督が包括の業務 | → 多くは施設ケアマネ・本人等・**市町村**の業務 |
| 最初の窓口＝福祉事務所・地活・居宅介護支援・認知症疾患医療センター | → まずは**地域包括** |

## 6　指定・人員

### 覚えること

- **都道府県**が指定・監督するものの例として問われた: **施設サービス**。
- **市町村**が指定・監督: 地域密着型、居宅介護支援、夜間対応型訪問介護、介護予防支援など。
- 介護老人福祉施設などで、**施設サービス計画の作成は介護支援専門員**が行う。
- 居宅介護支援事業所に義務づけられる職種として問われた: **介護支援専門員**（主任ケアマネ・ヘルパー・サ責・福祉用具専門相談員の必置ではない）。

|----------|------------|

## 7　会議・計画

### 覚えること

- **サービス担当者会議**: 介護支援専門員が**招集・主催**。居宅サービス計画の原案説明もケアマネ。自宅開催・月1回義務・匿名化は必須ではない。目的は利用者の支援内容の検討。
- **訪問介護計画**は、**居宅サービス計画の方針に沿って**作成する（順序は居宅が先）。目標変更時は訪問介護計画も見直す。転記や逆順は×。
- サービス担当者会議での訪問介護員の役割の例: **訪問介護計画作成に必要な情報の確認**（主催や居宅原案説明はケアマネ）。
- **認知症対応型共同生活介護計画**は、グループホーム入居時に**事業所側**が作成。認知症があっても説明と同意は省略できない。居宅介護支援事業所へ依頼しない。
- 通所の都合が合わない等は、まず**担当ケアマネに再調整を依頼**。
- 他事業所への苦情は、まずその**事業所の苦情対応の仕組み**へ（審査会や日常生活自立支援事業が第一ではない）。
- 利用継続・負担の悩みは、ヘルパー単独で生活保護・借入・扶養勧奨せず、**担当ケアマネに検討を依頼**。

### ×になりやすい点（会議の取り違え）

| 会議名 | 国試での位置づけ |
|--------|------------------|
| サービス担当者会議 | ケアマネが招集しケアプランを検討 |
| 退院前カンファレンス | 病院中心の退院調整 |
| 地域ケア会議 | 個別・地域課題 |
| 支援調整会議 | 生活困窮者支援など |
| 介護・医療連携推進会議 | 定期巡回などの運営協議 |

## 8　訪問・通所・短期入所サービス

### 覚えること

#### 誰が使えるか

- **夜間対応型訪問介護**・**定期巡回・随時対応型訪問介護看護**: **要介護者**（要支援は不可）。
- **介護予防**・**総合事業（第一号）**は要支援・事業対象者向け。例: 介護予防住宅改修、第一号訪問・通所、介護予防小規模多機能。

#### サービスの見分け

- **定期巡回・随時対応型訪問介護看護**: 日中・夜間を通じ提供。随時訪問可。定員の定めなし。地域密着型で**市町村**が指定。通い・泊まりの組合せ説明は小多機側。
- **小規模多機能型居宅介護**（予防含む）: **通い・泊まり・訪問**を一体で。自宅継続＋交流＋息子の泊まり出張などに合う。
- **看護小規模多機能型居宅介護**: **看護と介護を一体的に**。地域密着型。長期間の宿泊が目的ではない。
- **短期入所生活介護（ショートステイ）**: 家族の短期間不在（入院など）の穴埋めで適切。
- **認知症対応型通所介護**: 原則**事業所のある市町村の住民**が利用。

#### 訪問介護でできる／できない

- **できる例**: 生活等に関する相談・助言、習慣に沿った掃除の同行、処方薬の薬局受け取り。
- **できない例**: 庭の植木の水やり、ペットフード購入、ラーメン屋同行、カード預かり買物代行、本人不在時の洗濯取り込み、お祭り同行、壁紙張替え、来客へのお茶、通帳印鑑預かり、庭の草むしり、訪問日以外の安否確認、理美容。

#### 総合事業

- 総合事業に含まれる例: **第一号訪問事業（訪問型サービス）**。
- 含まれない／別物: 家族介護支援事業、予防給付・介護給付そのもの、権利擁護事業。

### ×になりやすい点

| ×の主張 | 正しい側 |
|----------|----------|
| 要支援に夜間対応型・定期巡回 | → **要介護のみ** |
| 小多機＝趣味のカラオケ目的だけ | → 生活全体を支えるサービス |
| 定期巡回に利用定員9人以下 | → **定員の定めなし** |
| 定期巡回＝通い・泊まり・看護の3種組合せ | → それは**小多機**側の説明 |
| 看護小多機＝居宅サービス／都道府県域 | → **地域密着型・市町村区域** |
| 自宅継続希望なのにGH・特養を第一提案 | → 通所型・小多機・ショートなど在宅側 |

## 9　共同生活・施設サービス

### 覚えること

- **介護老人保健施設**: 在宅復帰を目指すリハビリ・一定期間の入所向き。
- **介護老人福祉施設**: 生活施設での長期介護が中心。
- **介護医療院**: 長期の医療・介護。入所は要介護者（要介護3以上限定ではない）。開設許可は**都道府県知事等**。レクリエーション行事に努める。サービス管理責任者の必置はない（障害福祉の話）。
- **認知症対応型共同生活介護（グループホーム）**: 家庭的雰囲気、なじみの関係の継続、地域とのかかわり、その人らしい生活。1ユニット定員は原則**9人まで**。機能訓練も行う。一律日課・車いす押し進めは×。
- **ユニット型**の考え方: 家族等が気軽に宿泊できる配慮。一律の食事時間強要や、外出せず施設内完結は×。
- **特定施設入居者生活介護**: 養護老人ホーム等での継続生活の説明として問われた。
- 平成29年改正で問われた例: **介護医療院の創設**（定期巡回創設は平成24年、在宅医療・介護連携の地域支援事業位置づけは平成27年などと区別）。

### ×になりやすい点

| ×の主張 | 正しい側 |
|----------|----------|
| 老健＝養護・軽費・特養・医療院と同じ | → 在宅復帰リハなら**老健** |
| GHの1ユニット10名まで | → 原則**9人**まで |
| GHは地域と関わらない／機能訓練しない／一律日課 | → 地域・機能訓練・個別の生活 |
| 介護医療院＝要介護3以上のみ／市町村許可／サビ管必置 | → 要介護者／都道府県等／サビ管は不要 |

出典: 36-117、33-23、32-22、31-13、31-119、29-39、29-70

## 10　福祉用具サービス

### 覚えること

- 自立して調理・買物したい希望には、**福祉用具の活用**や**福祉用具専門相談員の助言（例: 四輪歩行車）**が合う。
- 自宅入浴を続けたい・浴槽から立ち上がりにくい → まず**特定福祉用具販売（入浴補助用具）**を検討。
- ヘルパーの調理代行・配食・通所の入浴は、「自分でやりたい／自宅で続けたい」が主目的のときは第一選択になりにくい。
- 自立生活援助・行動援護・大がかりな浴室改築は、入浴補助の第一提案としては遠い。

### ×になりやすい点

| 本人の希望 | ×になりやすい提案 | ○側 |
|------------|-------------------|------|
| 左手で調理したい | 調理代行・配食・ヘルパー交代 | **調理用福祉用具** |
| 食材を自分で選びたい | 配食・日常生活自立支援・通所入浴 | **四輪歩行車等＋専門相談員** |
| 自宅で入浴を続けたい | 通所入浴・行動援護・広い浴室への改築が先 | **入浴補助用具（特定福祉用具販売）** |

出典: 37-111、36-69、33-24

## 横断チェックリスト（頻出の取り違え）

1. **誰が保険者か** → 市町村・特別区  
2. **何歳が何号か** → 65〜が1号、40〜64（医療保険）が2号  
3. **誰が保険料を取るか** → 1号＝市町村、2号＝医療保険者  
4. **財源の3本柱** → 公費・1号・2号  
5. **負担割合** → 1〜3割（一律1割ではない）  
6. **市町村指定か都道府県指定か** → 地域密着・居宅介護支援は市町村、施設は都道府県側が典型
