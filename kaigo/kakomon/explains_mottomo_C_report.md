## Layer C の定義

- 問題文に「**最も適切なもの**」を含む問のうち、**生活支援の手技・場面**（移乗・体位・整容・入浴・排泄・食事・住環境・終末期の生活支援など）
- 併せて同型の **医療的ケア手技**、およびこころとからだのうち手技・好発部位に近い問を含む
- Layer A／B・総合問題（D）は除外
- キュー: `explains_mottomo_C_queue.json`（**252問**）
- ソースダンプ: `_mottomo_C_dump.txt`

除外した境界例: マズロー／防衛機制／疾患同定、介護過程の目標・ICF、声かけ中心の生活支援問（`30-80` 等）

## 方針（スタイル・ハルシネ抑制）

- **文脈拘束**: ○は条件（麻痺側・能力・目的）＋なぜその手技が合うか。✕は手技・用具の短い正体＋この条件に合わない理由
- **教科書1行まで**: 角度・温度・時間・深さなどの数値は設問／選択肢にない限り断定しない
- **図依存**: 図がない問は選択肢文言のみで柔らかく書き、要確認へ
- **短文可**: 1〜2文（1文強制なし）
- 微妙な手技・法令・数値は `explains_mottomo_C_needs_review.md` に記録
