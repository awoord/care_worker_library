# 解説データ（下書き〜公開）

## 方針
- 外国人にも分かる、短いやさしい日本語
- 根拠は問題文・選択肢の内容に限る（書いてないことは書かない）
- 正解は `answers_*.csv` を正とする
- まず正解選択肢の1文解説から始める（不正解は必要なら後から）

## ファイル
- `explains_38.json` など回ごと
- ビルド時に `questions.json` の各問へ `explains` をマージする

## 形式
```json
{
  "session": 38,
  "items": {
    "38-1": {
      "status": "draft",
      "explains": {
        "2": "正解の短い説明（選択肢番号がキー）"
      }
    }
  }
}
```

- `status`: `draft`（未確認） / `reviewed`（確認済み）
- `explains`: 選択肢番号 → 表示文。空の選択肢は出さない
- 自信がないときは文末に「（要確認）」を付ける
